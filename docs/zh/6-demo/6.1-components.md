# 6.1 Markdown 组件总览

本页演示文档系统支持的所有扩展 Markdown 组件。这些组件可以直接写在 `docs/` 目录下的 Markdown 文档中，渲染时自动生效。

## GFM 警告（Alerts）

使用 GitHub 风格的 `> [!TYPE]` 语法，支持五种类型：

> [!NOTE]
> 这是一条备注，用于补充说明性的信息。

> [!TIP]
> 这是一条提示，用于给出有帮助的建议。

> [!IMPORTANT]
> 这是一条重要信息，用户完成目标前必须了解的关键内容。

> [!WARNING]
> 这是一条警告，需要用户立即注意的风险内容。

> [!CAUTION]
> 这是一条危险提醒，说明某个操作可能带来的负面后果。

语法如下：

```md
> [!NOTE]
> 这是一条备注。

> [!WARNING]
> 这是一条警告。
```

## 代码块

代码块支持语法高亮、一键复制和语言标签：

```ts
interface Provider {
  id: string;
  name: string;
  baseUrl: string;
}

export function switchProvider(provider: Provider) {
  console.log(`切换到 ${provider.name}`);
}
```

通过 `title="..."` 可以给代码块加标题（常用于展示文件名）：

```json title="~/.cc-switch/config.json"
{
  "current": "anthropic",
  "providers": [{ "id": "anthropic", "name": "Anthropic 官方" }]
}
```

语法如下：

````md
```json title="~/.cc-switch/config.json"
{ "current": "anthropic" }
```
````

## 代码块分组（code-tabs）

多段代码可以合并为一组选项卡。`#id` 相同的分组会全页联动切换，`@tab:active` 指定默认选中项：

::: code-tabs#package-manager

@tab pnpm

```bash
pnpm add cc-switch
```

@tab:active npm

```bash
npm install cc-switch
```

@tab yarn

```bash
yarn add cc-switch
```

:::

下面是另一组使用相同 `#package-manager` 的代码组，点击上面的选项卡试试联动效果：

::: code-tabs#package-manager

@tab pnpm

```bash
pnpm dev
```

@tab:active npm

```bash
npm run dev
```

@tab yarn

```bash
yarn dev
```

:::

语法如下：

````md
::: code-tabs#package-manager

@tab pnpm

```bash
pnpm add cc-switch
```

@tab:active npm

```bash
npm install cc-switch
```

:::
````

## 选项卡（tabs）

`tabs` 容器中可以放任意 Markdown 内容，不限于代码：

::: tabs

@tab Windows

1. 下载 `.msi` 安装包
2. 双击运行安装向导

> [!TIP]
> Windows 下配置文件位于 `%USERPROFILE%\.cc-switch\`。

@tab macOS

1. 下载 `.dmg` 镜像
2. 将应用拖入「应用程序」文件夹

@tab Linux

使用 AppImage 或 deb 包安装：

```bash
sudo dpkg -i cc-switch_amd64.deb
```

:::

语法如下：

```md
::: tabs

@tab Windows

Windows 的内容……

@tab macOS

macOS 的内容……

:::
```

## 图片

图片组件基于 [react-medium-image-zoom](https://github.com/rpearce/react-medium-image-zoom)，点击图片即可放大预览，并支持懒加载。使用 `![alt](url "标题")` 语法时，标题会渲染为图片下方的说明文字：

![CC Switch 主界面](../../assets/claude-desktop-panel.png "CC Switch 的 Claude Desktop 面板")

语法如下：

```md
![CC Switch 主界面](../../assets/claude-desktop-panel.png "CC Switch 的 Claude Desktop 面板")
```

## 组合使用

所有组件都可以互相嵌套，例如在选项卡中放置警告和代码块：

::: tabs

@tab 开发环境

> [!NOTE]
> 开发环境默认监听 `8080` 端口。

```bash title="启动开发服务器"
npm run dev
```

@tab 生产环境

> [!WARNING]
> 构建前请确认已经更新 `docs/menu.json` 中的菜单配置。

```bash title="构建生产版本"
npm run build
```

:::
