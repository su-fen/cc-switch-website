# 6.2 多级菜单示例

这个页面本身就是多级菜单的演示：它在左侧菜单中位于 **组件演示 → 进阶用法 → 多级菜单示例**，是一个三级菜单项。

## 菜单配置

左侧菜单完全由项目根目录的 `docs/menu.json` 驱动。每个菜单项通过 `items` 字段嵌套即可形成多级菜单，层级不限：

```json title="docs/menu.json"
{
  "id": "demo",
  "icon": "palette",
  "title": { "zh": "组件演示", "en": "Component Demo", "ja": "コンポーネントデモ" },
  "items": [
    {
      "id": "components",
      "title": { "zh": "Markdown 组件总览", "en": "Markdown Components", "ja": "Markdown コンポーネント" },
      "doc": "6-demo/6.1-components.md"
    },
    {
      "id": "advanced",
      "title": { "zh": "进阶用法", "en": "Advanced Usage", "ja": "高度な使い方" },
      "items": [
        {
          "id": "nested-menu",
          "title": { "zh": "多级菜单示例", "en": "Nested Menu Example", "ja": "多階層メニュー例" },
          "doc": "6-demo/6.2-nested-menu.md"
        }
      ]
    }
  ]
}
```

## 字段说明

| 字段 | 说明 |
| --- | --- |
| `id` | 菜单项 ID，同一分组内需要唯一，嵌套后组成 URL 中的 `item` 参数（如 `advanced/nested-menu`） |
| `title` | 多语言标题，`zh` 必填，`en` / `ja` 缺省时回退到中文 |
| `doc` | 相对 `docs/{语言}/` 的 Markdown 文件路径；不填则该项仅作为可展开的分组 |
| `items` | 子菜单数组，支持任意层级嵌套 |
| `icon` | 仅顶层分组支持，可选值见 `src/content/docs/navigation.tsx` 中的 `ICON_MAP` |
| `defaultItem` | 点击顶层分组标题时默认展示的子项 ID（缺省为第一个有文档的子项） |

> [!TIP]
> 新增文档时只需两步：把 Markdown 文件放进 `docs/zh/`（以及 `docs/en/`、`docs/ja/`，缺省回退中文），再到 `docs/menu.json` 中挂上菜单即可。搜索、上一页/下一页、SEO 和站点地图都会自动同步。
