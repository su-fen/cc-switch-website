# 6.1 Markdown コンポーネント

このページでは、ドキュメントシステムがサポートする拡張 Markdown コンポーネントをすべて紹介します。`docs/` ディレクトリ配下の Markdown ファイルにそのまま記述できます。

## GFM アラート

GitHub スタイルの `> [!TYPE]` 構文で、5 種類のアラートが使えます：

> [!NOTE]
> メモ — 補足的な情報を伝えます。

> [!TIP]
> ヒント — 役に立つアドバイスを伝えます。

> [!IMPORTANT]
> 重要 — 目的を達成するために必ず知っておくべき情報です。

> [!WARNING]
> 警告 — すぐに注意が必要な内容です。

> [!CAUTION]
> 注意 — 操作によるリスクや悪影響を知らせます。

構文：

```md
> [!NOTE]
> これはメモです。

> [!WARNING]
> これは警告です。
```

## コードブロック

コードブロックはシンタックスハイライト、ワンクリックコピー、言語ラベルに対応しています：

```ts
interface Provider {
  id: string;
  name: string;
  baseUrl: string;
}

export function switchProvider(provider: Provider) {
  console.log(`${provider.name} に切り替えます`);
}
```

`title="..."` でタイトルバー（ファイル名など）を追加できます：

```json title="~/.cc-switch/config.json"
{
  "current": "anthropic",
  "providers": [{ "id": "anthropic", "name": "Anthropic 公式" }]
}
```

構文：

````md
```json title="~/.cc-switch/config.json"
{ "current": "anthropic" }
```
````

## コードタブ（code-tabs）

複数のコードブロックをタブとしてまとめられます。同じ `#id` を持つグループはページ全体で連動して切り替わり、`@tab:active` でデフォルトのタブを指定します：

::: code-tabs#package-manager

@tab pnpm

```bash
pnpm add cc-switch
```

@tab:active npm

```bash
npm install cc-switch
```

@tab yarn

```bash
yarn add cc-switch
```

:::

以下は同じ `#package-manager` を使う別のグループです。上のタブをクリックすると連動します：

::: code-tabs#package-manager

@tab pnpm

```bash
pnpm dev
```

@tab:active npm

```bash
npm run dev
```

@tab yarn

```bash
yarn dev
```

:::

構文：

````md
::: code-tabs#package-manager

@tab pnpm

```bash
pnpm add cc-switch
```

@tab:active npm

```bash
npm install cc-switch
```

:::
````

## タブ（tabs）

`tabs` コンテナにはコードに限らず任意の Markdown コンテンツを入れられます：

::: tabs

@tab Windows

1. `.msi` インストーラーをダウンロード
2. セットアップウィザードを実行

> [!TIP]
> Windows では設定ファイルは `%USERPROFILE%\.cc-switch\` にあります。

@tab macOS

1. `.dmg` イメージをダウンロード
2. アプリを「アプリケーション」フォルダにドラッグ

@tab Linux

AppImage または deb パッケージでインストールします：

```bash
sudo dpkg -i cc-switch_amd64.deb
```

:::

構文：

```md
::: tabs

@tab Windows

Windows 向けの内容……

@tab macOS

macOS 向けの内容……

:::
```

## 画像

画像コンポーネントは [react-medium-image-zoom](https://github.com/rpearce/react-medium-image-zoom) をベースにしており、クリックで拡大表示、遅延読み込みに対応しています。`![alt](url "タイトル")` 構文を使うと、タイトルが画像の下にキャプションとして表示されます：

![CC Switch メイン画面](../../assets/claude-desktop-panel-ja.png "CC Switch の Claude Desktop パネル")

構文：

```md
![CC Switch メイン画面](../../assets/claude-desktop-panel-ja.png "CC Switch の Claude Desktop パネル")
```

## 組み合わせ

すべてのコンポーネントは自由にネストできます。例えばタブの中にアラートとタイトル付きコードブロックを入れられます：

::: tabs

@tab 開発環境

> [!NOTE]
> 開発サーバーはデフォルトでポート `8080` で待ち受けます。

```bash title="開発サーバーを起動"
npm run dev
```

@tab 本番環境

> [!WARNING]
> ビルド前に `docs/menu.json` のメニュー設定が最新か確認してください。

```bash title="本番ビルド"
npm run build
```

:::
