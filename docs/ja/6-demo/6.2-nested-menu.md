# 6.2 多階層メニュー例

このページ自体が多階層メニューのデモです。サイドバーでは **コンポーネントデモ → 高度な使い方 → 多階層メニュー例** の下にある、3 階層目のメニュー項目です。

## メニュー設定

サイドバーはプロジェクトルートの `docs/menu.json` によって完全に制御されます。`items` フィールドをネストするだけで、任意の深さのメニューを作れます：

```json title="docs/menu.json"
{
  "id": "demo",
  "icon": "palette",
  "title": { "zh": "组件演示", "en": "Component Demo", "ja": "コンポーネントデモ" },
  "items": [
    {
      "id": "components",
      "title": { "zh": "Markdown 组件总览", "en": "Markdown Components", "ja": "Markdown コンポーネント" },
      "doc": "6-demo/6.1-components.md"
    },
    {
      "id": "advanced",
      "title": { "zh": "进阶用法", "en": "Advanced Usage", "ja": "高度な使い方" },
      "items": [
        {
          "id": "nested-menu",
          "title": { "zh": "多级菜单示例", "en": "Nested Menu Example", "ja": "多階層メニュー例" },
          "doc": "6-demo/6.2-nested-menu.md"
        }
      ]
    }
  ]
}
```

## フィールド一覧

| フィールド | 説明 |
| --- | --- |
| `id` | メニュー項目 ID。同じグループ内で一意。ネストすると URL の `item` パラメータになります（例：`advanced/nested-menu`） |
| `title` | 多言語タイトル。`zh` は必須、`en` / `ja` は省略時に中国語へフォールバック |
| `doc` | `docs/{言語}/` からの相対 Markdown パス。省略するとその項目は展開専用のグループになります |
| `items` | 子メニュー配列。任意の深さでネスト可能 |
| `icon` | トップレベルのセクションのみ。候補は `src/content/docs/navigation.tsx` の `ICON_MAP` を参照 |
| `defaultItem` | セクション見出しをクリックしたときに表示する子項目 ID（省略時はドキュメントを持つ最初の子項目） |

> [!TIP]
> 新しいドキュメントの追加は 2 ステップです。Markdown ファイルを `docs/zh/`（および `docs/en/`、`docs/ja/`。未翻訳は中国語にフォールバック）に置き、`docs/menu.json` にメニューを登録するだけ。検索・前後ページ・SEO・サイトマップはすべて自動的に同期されます。
