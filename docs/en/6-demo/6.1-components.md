# 6.1 Markdown Components

This page demonstrates all the extended Markdown components supported by the documentation system. You can use them directly in any Markdown file under the `docs/` directory.

## GFM Alerts

GitHub-style `> [!TYPE]` syntax with five types:

> [!NOTE]
> A note — supplementary information for the reader.

> [!TIP]
> A tip — helpful advice for doing things better.

> [!IMPORTANT]
> Important — key information users need to know to achieve their goal.

> [!WARNING]
> A warning — urgent info that needs immediate attention.

> [!CAUTION]
> Caution — advises about risks or negative outcomes of an action.

Syntax:

```md
> [!NOTE]
> This is a note.

> [!WARNING]
> This is a warning.
```

## Code Blocks

Code blocks support syntax highlighting, one-click copy and a language label:

```ts
interface Provider {
  id: string;
  name: string;
  baseUrl: string;
}

export function switchProvider(provider: Provider) {
  console.log(`Switching to ${provider.name}`);
}
```

Use `title="..."` to add a title bar (commonly a file name):

```json title="~/.cc-switch/config.json"
{
  "current": "anthropic",
  "providers": [{ "id": "anthropic", "name": "Anthropic Official" }]
}
```

Syntax:

````md
```json title="~/.cc-switch/config.json"
{ "current": "anthropic" }
```
````

## Code Tabs

Group multiple code blocks into tabs. Groups sharing the same `#id` switch together across the whole page, and `@tab:active` marks the default tab:

::: code-tabs#package-manager

@tab pnpm

```bash
pnpm add cc-switch
```

@tab:active npm

```bash
npm install cc-switch
```

@tab yarn

```bash
yarn add cc-switch
```

:::

Here is another group using the same `#package-manager` id — click a tab above and watch them switch together:

::: code-tabs#package-manager

@tab pnpm

```bash
pnpm dev
```

@tab:active npm

```bash
npm run dev
```

@tab yarn

```bash
yarn dev
```

:::

Syntax:

````md
::: code-tabs#package-manager

@tab pnpm

```bash
pnpm add cc-switch
```

@tab:active npm

```bash
npm install cc-switch
```

:::
````

## Tabs

A `tabs` container accepts any Markdown content, not just code:

::: tabs

@tab Windows

1. Download the `.msi` installer
2. Run the setup wizard

> [!TIP]
> On Windows the config files live in `%USERPROFILE%\.cc-switch\`.

@tab macOS

1. Download the `.dmg` image
2. Drag the app into the Applications folder

@tab Linux

Install via AppImage or the deb package:

```bash
sudo dpkg -i cc-switch_amd64.deb
```

:::

Syntax:

```md
::: tabs

@tab Windows

Content for Windows…

@tab macOS

Content for macOS…

:::
```

## Images

The image component is powered by [react-medium-image-zoom](https://github.com/rpearce/react-medium-image-zoom): click an image to zoom in, with lazy loading built in. With the `![alt](url "title")` syntax, the title renders as a caption below the image:

![CC Switch main window](../../assets/claude-desktop-panel-en.png "The Claude Desktop panel in CC Switch")

Syntax:

```md
![CC Switch main window](../../assets/claude-desktop-panel-en.png "The Claude Desktop panel in CC Switch")
```
