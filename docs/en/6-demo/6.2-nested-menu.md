# 6.2 Nested Menu Example

This page is itself a demo of multi-level menus: in the sidebar it lives under **Component Demo → Advanced Usage → Nested Menu Example** — a third-level menu item.

## Menu configuration

The sidebar is fully driven by `docs/menu.json` at the project root. Nest menu entries via the `items` field to create menus of any depth:

```json title="docs/menu.json"
{
  "id": "demo",
  "icon": "palette",
  "title": { "zh": "组件演示", "en": "Component Demo", "ja": "コンポーネントデモ" },
  "items": [
    {
      "id": "components",
      "title": { "zh": "Markdown 组件总览", "en": "Markdown Components", "ja": "Markdown コンポーネント" },
      "doc": "6-demo/6.1-components.md"
    },
    {
      "id": "advanced",
      "title": { "zh": "进阶用法", "en": "Advanced Usage", "ja": "高度な使い方" },
      "items": [
        {
          "id": "nested-menu",
          "title": { "zh": "多级菜单示例", "en": "Nested Menu Example", "ja": "多階層メニュー例" },
          "doc": "6-demo/6.2-nested-menu.md"
        }
      ]
    }
  ]
}
```

## Field reference

| Field | Description |
| --- | --- |
| `id` | Menu item ID, unique within its group; nested IDs join into the `item` URL param (e.g. `advanced/nested-menu`) |
| `title` | Localized titles; `zh` is required, `en` / `ja` fall back to Chinese |
| `doc` | Markdown file path relative to `docs/{lang}/`; omit it to make the entry a pure expandable group |
| `items` | Child entries, nested to any depth |
| `icon` | Top-level sections only; see `ICON_MAP` in `src/content/docs/navigation.tsx` |
| `defaultItem` | Child ID shown when clicking the section header (defaults to the first child with a doc) |

> [!TIP]
> Adding a new document takes two steps: drop the Markdown file into `docs/zh/` (plus `docs/en/`, `docs/ja/` — missing translations fall back to Chinese), then register it in `docs/menu.json`. Search, prev/next navigation, SEO and the sitemap all stay in sync automatically.
